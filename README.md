# Gala Solar - Website

A professional, single-page, responsive website for Gala Solar.

## Features
- **High-Contrast Theme:** Deep Slate/Navy background with Bright Amber/Yellow accents for a professional, striking look.
- **Fully Responsive:** Adapts perfectly to mobile, tablet, and desktop screens using Tailwind CSS.
- **Single Page Architecture:** Smooth scrolling navigation encompassing Home, About, Products, and Contact.
- **GitHub Pages Ready:** Uses Tailwind CSS via CDN. Zero build steps required.

## How to deploy on GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this `.zip` file directly to the root of your new repository.
3. Go to the repository **Settings**.
4. Navigate to **Pages** on the left sidebar.
5. Under **Source**, select the `main` branch and `/root` folder.
6. Click **Save**. Your site will be live and rendering perfectly in a few minutes!
